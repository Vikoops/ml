## Содержание репозитория

- lab1.ipynb - полный цикл решения задачи регрессии: анализ датасета, очистка данных, корреляционный анализ, выявление мультиколлинеарности, построение моделей линейной и гребневой регрессии, применение PCA и сравнение качества моделей (RMSE, R², MAPE)
- lab2.ipynb - анализ ассоциативных правил: исследование транзакционных данных, применение алгоритмов Apriori и FP-Growth, настройка параметров (support, confidence), анализ метрик (lift, confidence), интерпретация и визуализация правил
- lab3.ipynb - задача классификации: построение и сравнение моделей (Naive Bayes, Decision Tree, LDA, SVM, k-NN), оценка качества (accuracy, precision, recall, F1, ROC-AUC), настройка гиперпараметров, реализация нейронной сети в TensorFlow с визуализацией обучения
- lab4.ipynb - кластеризация данных: дескриптивный анализ, стандартизация признаков, применение методов кластеризации (K-means, иерархическая, DBSCAN или EM), подбор параметров, оценка качества кластеров и их интерпретация

- mad_rgz.ipynb - расширенное исследование кластеризации: сравнение различных алгоритмов, анализ метрик качества, исследование влияния параметров, визуализация кластеров с использованием PCA и интерпретация результатов

- rgz.ipynb - итоговый проект по машинному обучению: разработка модели для распознавания эмоций по лицу, обучение и оценка модели, анализ эффективности и применимости выбранного подхода
- app.py - приложение на Streamlit для распознавания эмоций: загрузка изображения или работа с камерой, детекция лица (Haar Cascade), предобработка изображения и классификация эмоции с использованием обученной модели (TensorFlow)
